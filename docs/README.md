## Diagrams

[`diagrams/`](diagrams/) holds 23 PNGs at 200 dpi, drawn programmatically with
matplotlib — no external tooling, no manual editing, regenerated by
`build_diagrams.py`. They are embedded in the two design documents and are
reusable in slides.

**Functional** — system context · capability map · the four quantities ·
portfolio distance and role modes · lifecycle · collaboration · the evidence
funnel and the four defences · market sizing · screens and role journeys ·
conceptual data model · competitor intelligence.

**Technical** — layered architecture · the pipeline · refresh sequence · read
sequence · deployment · scoring · physical data model in five parts · model
guardrails.

## Rebuilding

```bash
python3 docs/build_diagrams.py     # the 23 PNGs
python3 docs/build_reference.py    # API.md and DATA_MODEL.md, from live code
python3 docs/build_docs.py         # the two .docx files
```

`build_reference.py` reads the running FastAPI app and the live SQLite schema, so
the API and data-model references cannot drift from the code. The narrative
documents are hand-written and need judgement to update — the build script only
assembles them.
